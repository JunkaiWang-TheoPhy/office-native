# Banner visual thesis

The skill's defining action is selecting the user's real editing surface. The banner shows one active document, one selected object, and a direct route from the agent's terminal to that object. The tabs on the same document hint at prose, slides, and cells without depicting three separate output files.

The first direction was rejected because it added slogans and desk props that obscured the route. The chosen banner remains legible at 600 px wide: terminal, route, selection, and document tabs are still distinct. It is an illustration of the workflow, not evidence that an Office application or MCP session is connected.
